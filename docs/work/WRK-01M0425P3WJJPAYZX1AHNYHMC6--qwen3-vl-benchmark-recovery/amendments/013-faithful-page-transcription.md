# Amendment: restore faithful page transcription

The page-transformation prompt must use a concise handwriting-transcription
instruction set: preserve visible wording, spelling, capitalization,
punctuation, shorthand, unfamiliar terminology, and genuine uncertainty;
forbid semantic correction, autocorrection, invention, and context-based
substitution. Graphical arrows, strokes, lines, and connectors that clearly
function as diagram graphics are excluded from page text.

Spatial proximity does not determine ownership. A handwritten word remains
eligible for page text when it is near, beside, above, below, or adjacent to a
drawing. Remove overly restrictive figure-adjacency language and do not add
specimen-specific vocabulary or correction logic.

Only the page prompt and mocked prompt-contract coverage are in scope. The
drawing-localization prompt, schema, Qwen coordinate conversion, mapping,
padding, crops, projections, provenance, timing, and transform architecture
remain unchanged. No ADR change or model inference is authorized.
