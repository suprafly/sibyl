# Decisions

This architectural phase produces the following six accepted ADRs:

- ADR-0001 — Sibyl is a visual transformation system
- ADR-0002 — Text transformation and figure extraction are separate responsibilities
- ADR-0003 — Model implementations are subordinate to transformation contracts
- ADR-0004 — Visual artifacts preserve source pixels
- ADR-0005 — Source coordinates are authoritative for derived visual artifacts
- ADR-0006 — Transformation preserves interpretation and uncertainty
